## 結論だけ先に

リサーチでわかったこと（詳細は [02-market-research.md](docs/02-market-research.md)）。

1. **「生き物 雑学」は穴。** 月18,561検索・前月比+21.8%なのに競合度22.4。一般雑学は需要が落ちている。
2. **尺は30秒。** 大手の平均28〜33秒。生き物特化の既存勢は50〜60秒で止まっている。
3. **巨大競合は他人の映像の転載で回している。** 同じ土俵では戦えないし、戦うべきでもない。
4. **勝ち筋は「身近な生き物 × 出典つき」。** 珍獣・深海・最強ランキングは飽和。
   カラス、スズメ、ダンゴムシ——**明日その辺で確かめられる**ネタは競合が手薄。
5. **既存チャンネル（37登録・音楽系）は使わず新規開設を推奨。** トピックが食い違うと初動で不利。
6. **タイトルは体言止め「〜理由」。** 同じ内容でもです・ます調にすると23点落ちる（86点 → 56点）。
   ただし**ナレーション本文は敬体で統一**する。1,000万再生級の2本はどちらも文体が完全統一されていた。
7. **市場は止まっていない。** 大手ゆっくり系は月+1%未満で頭打ちの一方、1,700〜7,000人規模が月+24〜183%で伸びている。

| 投稿 | 毎日 21:00、予約投稿 |
