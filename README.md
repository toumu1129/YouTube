## 結論だけ先に

リサーチでわかったこと（詳細は [02-market-research.md](docs/02-market-research.md)）。

1. **「生き物 雑学」は穴。** 月18,561検索・前月比+21.8%なのに競合度22.4。一般雑学は需要が落ちている。
2. **尺は30秒。** 大手の平均28〜33秒。生き物特化の既存勢は50〜60秒で止まっている。
3. **巨大競合は他人の映像の転載で回している。** 同じ土俵では戦えないし、戦うべきでもない。
4. **勝ち筋は「身近な生き物 × 出典つき」。** 珍獣・深海・最強ランキングは飽和。
   カラス、スズメ、ダンゴムシ——**明日その辺で確かめられる**ネタは競合が手薄。
5. **既存チャンネル（37登録・音楽系）は使わず新規開設を推奨。** トピックが食い違うと初動で不利。

## 最初の14日

| 日 | やること |
|---:|---|
| 1 | チャンネル名を決める → 新規チャンネル開設、アイコン・概要欄を設定 |
| 2 | `s001`〜`s003` の出典を原典で確認（[06](docs/06-fact-checking.md) の基準で） |
| 3 | 編集テンプレートを1つ作る（テロップ書体・位置・色を固定） |
| 4 | ナレーション3本を一気に録る |
| 5 | 素材を集める。カラス・ハト・ダンゴムシは自分で撮れる |
| 6 | 編集3本 |
| 7 | **初投稿。** 以後 21:00 に予約投稿 |
| 8–13 | `s004`〜`s010` を同じ流れで。1日1本 |
| 14 | 数字を [metrics.md](docs/metrics.md) に記録。**維持率70%を切っていたら尺を25秒に詰める** |

**60本まではフォーマットを変えない。** 変えるときは1要素ずつ。

## 注意

`scripts/shorts/` の各台本にある**出典は「候補」であり、未検証**。
公開前に必ず原典に当たって、存在と内容を自分の目で確認すること。
特に `s004`（セミ）の日数など、**具体的な数字は確認できるまで台本に書かない**。
