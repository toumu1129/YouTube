# ファクトチェック基準

**このチャンネルの差別化は、ここにしかない。**
競合はほぼ全て出典なしで運用している。裏取りをやめた瞬間、ただの量産チャンネルになる。

---

## 1. 投稿してよい条件

次の**すべて**を満たすこと。ひとつでも欠けたら投稿しない。

1. **独立した出典が2つ以上ある**（同じ元ネタを引き写した記事は1つと数える）
2. そのうち**最低1つが一次情報**（論文・研究機関・博物館・図鑑）
3. 出典の**発行年が確認できる**
4. 台本の主張が、出典の主張を**誇張していない**

## 2. 出典の格付け

| ランク | 種類 | 例 |
|---|---|---|
| **A** | 査読論文、学会誌 | J-STAGE、PubMed、Nature、Science |
| **A** | 公的研究機関・博物館 | 国立科学博物館、水産研究・教育機構、各大学の研究室 |
| **B** | 専門家が書いた書籍・図鑑 | 監修者名が明記された図鑑、大学教員の一般書 |
| **B** | 動物園・水族館の公式解説 | 飼育員による解説ページ |
| **C** | 専門メディアの記事 | ナショナルジオグラフィック、科学系ニュース |
| **不可** | まとめサイト、他のYouTube動画、生成AIの出力のみ | — |

**C だけで2つ揃っても投稿しない。** 必ず A か B を1つ含める。

## 3. よくある「嘘の雑学」

これらは広く出回っているが誤り、または根拠が薄い。**扱うなら「誤りである」側から扱う。**

| 通説 | 実際 |
|---|---|
| セミの成虫は1週間で死ぬ | 野外調査で2〜4週間生きる個体が確認されている |
| 金魚の記憶は3秒 | 数か月単位の学習が実験で示されている |
| コウモリは目が見えない | 多くの種で視覚は機能している |
| レミングは集団自殺する | 1958年のディズニー映像の演出が広まったもの |
| ダチョウは砂に頭を埋める | 埋めない。巣の卵を確認しているのが誤認された |
| ナメクジは塩で溶ける | 溶けていない。浸透圧で水分が抜けて縮む |
| ニワトリは3歩で忘れる | 根拠なし |
| サメは病気にならない | なる。軟骨に抗がん作用があるという説も否定されている |

**「実は嘘だった」系はフックが強く、しかも正確。**このチャンネルの得意技にする。

## 4. 書きかたの規律

| やる | やらない |
|---|---|
| 「〜と考えられています」 | 「〜なのです」（仮説を断定しない） |
| 「2019年の調査では」 | 「最新の研究では」（いつの話かわからない） |
| 「まだわかっていません」 | わからない部分を省略して断定する |
| 「一部の種では」 | 一種の話を全体に広げる |

**「わかっていない」と言えることが、このチャンネルの信用になる。**
全部に答えが出ているチャンネルは、どこかで嘘をついている。

## 5. 訂正の手順

誤りが判明したら：

1. **動画は消さない**（消すと同じ誤りが他所で生き続ける）
2. 固定コメントに訂正文を置く
3. 説明欄の冒頭に「【訂正】」を追記する
4. 台本ファイルの末尾に訂正履歴を書く
5. 誤りが本筋に関わる場合のみ、訂正を扱った新作を1本出す

訂正文のひな形：
```
【訂正】この動画で「◯◯」と説明しましたが、正しくは「△△」です。
ご指摘ありがとうございました。出典：◯◯◯
```

## 6. 生成AIの扱い

- **ネタ出しには使ってよい。**
- **裏取りには使わない。** AIが挙げた出典は、必ず原典に当たって存在と内容を確認する。
- AIが出した数字・年号・研究者名は、**ひとつ残らず原典で確認する**。もっともらしい捏造が混ざる。
