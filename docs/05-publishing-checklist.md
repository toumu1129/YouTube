# 投稿チェックリスト

---

## 1. タイトル

**40字以内。スマホで2行に収まる長さ。**

型は [`03-shorts-format.md`](03-shorts-format.md) のフック型に対応させる。

| 型 | ひな形 | 実例 |
|---|---|---|
| D 不在の謎 | なぜ◯◯を見かけないのか | なぜカラスの死体を見かけないのか |
| C 常識の否定 | ◯◯は△△ではありません | セミは1週間では死にません |
| B なぜ疑問 | ◯◯はなぜ△△なのか | ハトはなぜ歩くとき首を振るのか |
| A 感情ラベル | ◯◯の切ない理由 | ゴキブリが仰向けで死ぬ切ない理由 |
| E 意外な対戦 | ◯◯と△△、じつは同じ□□ | キリンとネズミ、首の骨は同じ数 |

**やること**
- 生き物の名前を必ず入れる（検索で拾われる唯一の手がかり）
- 数字が使えるなら入れる（「7個」「32日」）
- 答えをタイトルに書かない。**問いだけ書く**

**やらないこと**
- 【衝撃】【ヤバい】などの記号乱用（この層には効かない上に安っぽく見える）
- 「〇〇3選」（ショートでは中身が薄くなる）
- タイトルに `#shorts` を入れる（説明欄で足りる）

## 2. 説明欄テンプレート

```
【今回の問い】カラスの死体はどこへ行くのか

弱ったカラスは人目につかない場所へ移動して死ぬこと、
そして死骸が数日で分解されることを30秒で解説しました。

━━━━━━━━━━
出典
・◯◯◯（書名／論文名、著者、発行年）
・◯◯◯（機関名のページ、URL、参照日）
━━━━━━━━━━

※わかっていないことは「わかっていない」と言う方針で作っています。
　誤りを見つけたらコメントで教えてください。訂正を固定します。

#生き物 #雑学 #豆知識 #カラス #動物 #shorts
```

**出典欄は必ず埋める。** 埋められないネタは投稿しない（→ [06-fact-checking.md](06-fact-checking.md)）。

## 3. ハッシュタグ

**5〜7個まで。** 詰め込むと逆に評価が下がる。

| 枠 | 中身 | 例 |
|---|---|---|
| 固定3つ | チャンネルの軸 | `#生き物` `#雑学` `#豆知識` |
| 可変2〜3つ | その回の生き物・テーマ | `#カラス` `#鳥` `#動物` |
| 必須1つ | フォーマット | `#shorts` |

## 4. 投稿設定

| 項目 | 設定 |
|---|---|
| 解像度 | 1080×1920（9:16） |
| 長さ | 25〜35秒 |
| 公開時刻 | **21:00**（通勤帰り〜就寝前の視聴が厚い時間帯） |
| 頻度 | 毎日1本。最低でも週5本 |
| 子ども向け | 「いいえ」 |
| 再生リスト | 生き物のカテゴリ別（鳥／虫／哺乳類／水の生き物） |
| 予約投稿 | 使う。手動投稿は必ず抜ける日が出る |

## 5. 投稿前の最終確認

- [ ] 出典を2つ以上、説明欄に書いた
- [ ] タイトルに生き物の名前が入っている
- [ ] タイトルは40字以内
- [ ] 最初の3秒に問いか否定がある
- [ ] 音を消してもテロップだけで意味が通る
- [ ] 下20%にテロップがかかっていない
- [ ] 使った素材のライセンスを台本ファイルに記録した
- [ ] 尺が35秒を超えていない

## 6. 投稿後

- **最初の2時間はコメントに全部返す。** 初速のエンゲージメントが配信量に効く。
- **誤りの指摘が来たら、固定コメントで訂正する。** 消さない。訂正した事実が信頼になる。
- 1週間後に YouTube Studio で以下を記録する（→ [`docs/metrics.md`](metrics.md) に追記）
  - 視聴回数 / 平均視聴維持率 / 最初の3秒の離脱率 / 登録者増
