## 1. 尺の設計：30秒・5ブロック

| ブロック | 秒 | 文字数目安 | 役割 |
|---|---:|---:|---|
| **① フック** | 0:00–0:03 | 15–25字 | 問いか、常識の否定。**1文だけ** |
| **② 共感** | 0:03–0:07 | 20–30字 | 「言われてみれば」を作る。視聴者の既知に触れる |
| **③ 答え** | 0:07–0:20 | 70–100字 | 理由をひとつだけ。**枝葉を切る** |
| **④ 納得** | 0:20–0:27 | 30–40字 | 一段深い含意。ここで「へぇ」が確定する |
| **⑤ 締め** | 0:27–0:30 | 10–15字 | 一言。問いかけかチャンネル名 |

**合計 150字以内。**

この数字は**実測した**。AI音声に読ませて計測した結果：

| 版 | 字数 | 実測 |
|---|---:|---:|
| s020 修正前 | 166字 | **31.63秒**（オーバー） |
| s020 修正後 | 151字 | **28.76秒** |

→ **5.25字/秒（6.29モーラ/秒）**。30秒に収まるのは **157字** まで。
安全マージンを見て **150字を上限**とする。

> 当初は「1秒6〜7字」としていたが、これは楽観的すぎた。
> 日本語は漢字1文字が2モーラ前後を持つので、**文字数は尺の指標として弱い**。
> 漢字率が高い文ほど、同じ字数でも長くなる。
>
> ⚠️ 上の実測値は ElevenLabs の音声によるもの。
> **使うエンジンを決めたら、必ず1本読ませて計り直すこと。**
> エンジンが変われば字数上限も変わる。

## 2. 文体 — 敬体で統一する

**述語で終わる文は、すべて敬体（です・ます）。常体は使わない。**
名詞や助詞で終わる短い断片（体言止め）はリズムのために使ってよい。**1本につき3つまで。**

```
◯  牛は草をほとんど噛まずに飲み込みます。
◯  一度飲んだら、一生入ったまま。         ← 体言止め。可
✕  そのまま胃に入ってしまう。              ← 常体。使わない
```

### なぜ混ぜないか

このニッチで1,000万再生を超えている2本を文字起こしで確認した結果、
**どちらも文体が完全に統一されていた。**

| 動画 | 再生 | 文体 |
|---|---:|---|
| なるほどずかん「馬の蹄を削る理由」 | 2,084万 | **敬体で統一**（常体ゼロ） |
| いきもののふしぎCH「悲しすぎるハイエナの生態」 | 1,219万 | 常体で統一（敬体ゼロ） |

どちらでも数字は出る。**ただし、混ぜている動画はなかった。**
文体を混ぜる手法は10分のドキュメンタリーの作法で、文が8〜10しかない30秒では、
切り替えそのものがノイズになる。

### 敬体を選んだ理由

1. このニッチで最も再生効率が高い なるほどずかん（登録2.29万で平均38.3万再生）が敬体統一
2. 「〜と考えられています」「まだわかっていません」という留保が自然に収まる。
   常体だと論文調になり、[06-fact-checking.md](06-fact-checking.md) の方針と噛み合わない
3. 常体統一は「ゆっくり解説」の定番文体で、同質化する。その検索需要自体が前月比 −9.7%

### コスト

敬体は常体より字数を食う（`s020` で比較すると 168字 対 151字、**約2.6秒ぶん**）。
200字の枠では効くので、**足すのではなく削って収める**こと。

## 3. 絶対ルール

1. **最初の3秒に「？」か「!」を置く。** 挨拶・自己紹介・チャンネル名を冒頭に入れない。
2. **理由はひとつ。** 「理由は3つあります」は長尺のやり方。ショートでは離脱する。
3. **専門用語は1本に1つまで**、しかも直後に言い換える。
   例：「交替性転向反応。つまり、右に曲がったら次は左」
4. **数字は具体的に。** 「長い」ではなく「32日」。「多い」ではなく「7個」。
5. **最後に次の動画を宣伝しない。** ショートは連続再生されるので、宣伝は離脱を生む。
6. **「いかがでしたか」「ぜひチャンネル登録を」は使わない。**
7. **常体（〜する／〜した／〜ない）で文を終えない。** 上の「文体」を参照。

## 4. フックの型（リサーチで実証済み）

| 型 | ひな形 | 例 |
|---|---|---|
| **D 不在の謎** | ◯◯を見かけないのはなぜか | 「カラスの死体、見たことある？」 |
| **C 常識の否定** | ◯◯は△△ではない | 「セミは1週間では死にません」 |
| **B なぜ疑問** | なぜ◯◯は△△なのか | 「ハトはなぜ首を振るのか」 |
| **A 感情ラベル** | 悲しすぎる／残酷すぎる◯◯ | 「ゴキブリが仰向けで死ぬ、切ない理由」 |
| **E 意外な対戦** | ◯◯より△△な□□ | 「キリンとネズミ、首の骨は同じ数」 |

D と C が最も強い。**迷ったら D か C にする。**

ただし**タイトルに落とすときは、必ず体言止め「〜理由」に変換する。**
フックは話し言葉（「セミは1週間では死にません」）でよいが、
タイトルを同じ文にすると弱くなる（スコア56 → 79）。詳細は [05](05-publishing-checklist.md)。

## 5. 画面構成とテロップ

```
┌─────────────┐
│  上 15%  空ける（UI）      │
├─────────────┤
│                             │
│   映像（生き物の実写・図解）│
│                             │
│   ┌───────────┐     │  ← テロップ帯
│   │  テロップ 1〜2行  │     │     画面中央やや上
│   └───────────┘     │
│                             │
├─────────────┤
│  下 20%  何も置かない（UI） │
└─────────────┘
```

### テロップ＝ナレーション全文

**テロップはナレーションと同じ文をそのまま出す。要約しない。**
だから台本のテロップ列は廃止し、ナレーション列がそのままテロップの原稿になっている。

| 秒 | ナレーション（＝テロップ全文） | 強調語 | 画面 |
|---|---|---|---|
| 0:07–0:20 | 牛は草をほとんど噛まずに飲み込みます。だから牧草に混ざった針金や釘まで、そのまま胃に入ってしまいます。 | 針金や釘 | 図解：飲み込み |

**なぜ全文か**

1. **AI音声では、耳だけで入らない語がある。**
   交替性転向反応（`s003`）／創傷性網胃炎（`s020`）／テオブロミン（`s024`）。
   人の声なら読みかたで補えるが、AI音声にその手はない。**テロップが唯一の保険**になる。
2. **実写素材が乏しいチャンネルでは、テロップが画の動きそのものになる。**
   自前撮影中心で映像は静かになりがち。文字が動き続けることが維持率に効く。
3. **中途半端にやると崩れる。** 要約テロップは「残りをどう出すか」を編集のたびに判断することになり、
   本数を重ねれば必ずぶれる。

### 表示ルール

- **1画面あたり 7〜12字 × 最大2行。** 超えたら分割する。改行位置は機械的にこの字数で決めてよい
- **縦位置は素材に合わせる。** 上の図は「中央やや上」を標準としているが、
  図解の被写体が画面中央に来る場合は**62〜78%の帯に下げる**。
  s020 で実測したところ、生成した図解は中央40〜75%を被写体が占めていた（→ [`assets/s020/README.md`](../assets/s020/README.md)）。
  **素材を作ったら、被写体の位置を見てからテロップの高さを決めること。**
- **切り替えはナレーションと同時。先出ししない。**
  読む速度は聞く速度より速いので、先に出すと答えがバレる
- **強調語だけアクセント黄。** 台本の「強調語」列がそれ。1画面に1語まで
- 白文字＋黒フチ3px。下20%にかからないこと

### 強調語列の使いかた

- **必ずナレーション中に実在する文字列**を書く（台本の全25本は検証済み）
- 強調が不要なブロックは `—`
- 13秒のブロックは2〜3画面に分かれるので、強調語が2つ入ることがある
- **強調はその文の半分を超えない。** 全部光っているのは光っていないのと同じ。
  ただし**①フックと⑤締めは3秒＝1画面**なので、述語ごと強調してよい（`s016`「研いでいません」など）

## 6. 音

| 要素 | 指定 |
|---|---|
| ナレーション | 落ち着いた男性／女性1名。テンションは上げない。内容で引っぱる |
| 速度 | 標準の1.05〜1.1倍。速すぎると聞き取れない |
| BGM | 環境音寄り、-28dB前後。メロディが強い曲は避ける |
| SE | ③の答えが出る瞬間に1回だけ。多用しない |

## 7. 台本ファイルの置き場所と命名

```
scripts/shorts/s001-karasu-no-shitai.md
                ^^^^ 連番    ^^^^^^^^^^ ローマ字スラッグ
```

1本＝1ファイル。ファイル内に次を全部入れる。
**収録・編集時にこのファイルだけ見れば完成する**状態にしておくこと。

| 節 | 中身 |
|---|---|
| タイトル案 | 3つ。第1候補は体言止め「〜理由」 |
| 台本 | 秒・ナレーション（＝テロップ全文）・強調語・画面 |
| **読み指定** | AI音声に当てる読み。**表示テキストは変えない**（→ [04](04-production-workflow.md)） |
| 出典 | 確認済みのものだけ。未確認は候補として残す |
| 素材 | 出どころとライセンス。権利者から連絡が来たとき即答できる状態に |
| 説明欄 | そのまま貼れる形 |
| 固定コメント案 | 投稿直後に置く |
| 訂正履歴 | 誤りが出たら追記。消さない |
