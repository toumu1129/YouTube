## 確認して判明したこと

裏取りは「出典を貼る作業」ではなく、**台本が間違っていないか調べる作業**だった。
9本のうち **5本で修正が必要**になった。

### 1. 私の記憶が間違っていた（s004）

セミの調査者を別人の名前で書いていた。正しくは **植松蒼さん**（岡山県立笠岡高等学校）。
**生成AIが挙げた人名・年号・論文名は、ひとつ残らず原典で確認すること**（[06](06-fact-checking.md) §6）。

### 2. 報道のほうが間違っていた（s004）

財経新聞ほか複数の記事が「**広島県**笠岡市の笠岡高校」と書いているが、
笠岡高校は**岡山県**笠岡市にある。学会の開催が広島大学だったための混同とみられる。
**二次情報が揃って同じ誤りを載せていることがある。** 一次情報（学校の公式サイト）まで降りて確認した。

### 3. 台本が出典を超えていた（s011）

「嗅ぐ時間を取った犬は落ち着きやすい」と書いていたが、
Duranton & Horowitz が示したのは**楽観的な判断バイアス**であって「落ち着く」ではない。
ナレーションを修正した。**これが一番危ない種類の誤り**——出典は実在するので、
貼っただけでは気づけない。

### 4. 原典のほうが良い数字を持っていた（s006・s021・s024）

ぼかして書いていた箇所に、確認したら具体的な数字があった。**3本とも差し替えた。**

| ID | 修正前 | 修正後 |
|---|---|---|
| s006 | ストレスの指標が明らかに早く下がりました | ストレスの値が **7日早く** 安定しました |
| s021 | 数年ぶりに見つかった羊が、何十キロもの毛を | **6年間** 逃げていた羊は、**27キロ** の毛を |
| s024 | 犬は分解が非常に遅いんです | 人間はおよそ**6時間**、犬は**17時間**かかります |

### 5. 確認できたが、あえて使わなかった（s024）

チョコレートの中毒量（mg/kg）は原典で確認できたが、**台本には入れない**。
具体的な量を示すと「これくらいなら平気」と読まれ、事故につながる。
代わりに半減期の対比を採用した。これなら安全量の計算に使えない。

## 残りを確認するときの順番

裏取りが楽で、かつ台本の中心を支えているものから。

1. `s003` 交替性転向反応 — 行動学の定番。文献はすぐ出る
2. `s012` ネコの乳糖不耐 — 獣医学の基礎
3. `s008` 哺乳類の頸椎7個 — 比較解剖学の定番
4. `s014` 硝化細菌 — 微生物学の基礎
5. `s025` ミツバチと燻煙 — 養蜂学
6. `s019` 鶏の連続照明 — 家禽学。**明期の時間数は言わない方針を維持すること**
7. `s017` メダカの塩水浴 — **濃度は言わない方針を維持すること**
8. `s015` ハトの餌やり — **「禁止している街がある」以上に踏み込まないこと**

`s001`（カラスの死体）は、実は**一次情報が出にくい**と見込まれる。
広く言われてはいるが、まとまった調査が見当たらない可能性がある。
その場合は「わかっていない」と正直に言う構成に組み替えるか、投稿順を後ろに回す。
