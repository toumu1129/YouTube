# チャンネル設計

リサーチ（[02-market-research.md](02-market-research.md)）にもとづく設計。

---

## 1. ひとことで

> **その辺にいる生き物の、誰も答えられない「なぜ」を30秒で。**

珍獣・深海生物・最強ランキングはやらない。**カラス、スズメ、ダンゴムシ、アリ、セミ、ネコ、ゴキブリ**——
視聴者が明日その辺で見かける生き物だけを扱う。

## 2. なぜこの切り口か

| 判断 | 根拠 |
|---|---|
| 生き物に絞る | 「生き物 雑学」は競合度22.4と低いのに需要は伸びている（+21.8%）。一般雑学は需要が落ちている |
| 身近な生き物に絞る | 珍獣・深海・最強系は既存チャンネルが飽和。身近系は断片的にしか手をつけられていない |
| 30秒 | 大手の平均28〜33秒。生き物特化の既存勢は50〜60秒のまま。短いほうが完視聴率で勝てる |
| 出典を明記する | 競合はほぼ全て出典なし。信頼は真似されにくい差別化で、YouTubeの量産コンテンツ扱いも避けられる |
| 自前・ライセンス素材 | 巨大競合は転載頼み。同じ土俵には立てないし、立つべきでもない |

## 3. 想定視聴者

- 20〜45歳、通勤・休憩・寝る前のスキマ時間
- 「へぇ」で終わらず、**誰かに話したくなる**ネタを探している
- 動物が好きというより、**知らないことがあるのが気持ち悪い**タイプ

## 4. 約束すること（コンセプト3条）

1. **1本＝1つの問い、1つの答え。** ランキングもまとめもやらない。
2. **出典が言えないネタは出さない。** 概要欄に必ず根拠を書く。
3. **断定しない部分は断定しない。** 「わかっていない」と言えるのを強みにする。

## 5. チャンネル名 — 決定：`生き物トリビア・雑学`

ハンドル案：`@ikimono_trivia`

**採用理由**：検索語（生き物／雑学）をそのまま含むため、発見性が最も高い。

**わかった上での弱点**：説明的な名前なので、指名検索や口コミで広がる力は弱い。
登録者が1万を超えて「指名で来る視聴者」が生まれた段階で、
**表示名だけ短い固有名に変え、ハンドルは据え置く**という手が残せる。その時まで判断は保留でよい。

### 検討した他の候補（将来の改名用に残す）

| 候補 | 狙い |
|---|---|
| となりの生きもの | 「身近」が一語で伝わる。覚えやすい |
| いきものメモ | 短く、ロゴにしやすい |
| 生きもののなぜ | ネタの型がそのまま名前になる |

## 6. チャンネル概要欄（そのまま使える案）

```
その辺にいる生き物の、誰も答えられない「なぜ」を30秒で。

カラスの死体はどこへ行くのか。ハトはなぜ首を振るのか。
セミは本当に1週間で死ぬのか。

珍獣も深海生物も出てきません。
扱うのは、あなたが明日どこかで見かける生き物だけです。

・1本につき、問いはひとつ。答えもひとつ。
・出典のないネタは出しません。各動画の概要欄に根拠を書いています。
・わかっていないことは「わかっていない」と言います。

毎日 21:00 更新。

#生き物 #雑学 #豆知識 #動物 #shorts
```

## 7. ビジュアル指針

| 項目 | 指定 |
|---|---|
| アイコン | 単色背景＋生き物のシルエット1つ（カラス推奨）。16pxでも判別できること |
| ブランドカラー | 深緑 `#1B4332` ／ アクセント黄 `#FFD60A` |
| テロップ書体 | 極太ゴシック（源ノ角ゴシック Heavy / LINE Seed JP Bold） |
| テロップ色 | 白文字＋黒フチ3px。強調語のみアクセント黄 |
| 配置 | 画面中央よりやや上。下20%はUIに隠れるので**何も置かない** |

### アイコン — 完成：[`assets/channel/icon.png`](../assets/channel/icon.png)（800×800）

カラスの頭部＋くちばし＋目だけのシルエット。深緑の背景に、目だけアクセント黄。

**全身シルエットは不採用にした。** 最初に止まり木に乗った全身像を作ったが、
48px以下に縮小すると脚と尾が潰れて黒い塊にしかならず、
「16pxでも判別できること」という自分で決めた基準を満たさなかった。
頭部のクローズアップに絞ってからは、48pxでも「鳥の頭＋くちばし＋黄色い目」と判別できる。

YouTubeのアイコン表示は多くの場面で48px以下（コメント欄・登録者一覧など）になるため、
**全身より部分、部分より「輪郭が単純な塊＋差し色の点」を優先する**のが、
このサイズ域では正しい判断だった。

## 8. ナレーション — 決定：AI音声（ElevenLabs または CoeFont）

量産に向き、声質がぶれないのが利点。運用ルールは [04-production-workflow.md](04-production-workflow.md) にまとめた。

**この選択で背負うリスク**：この領域はAI音声チャンネルが飽和していて、声そのものでは区別がつかない。
差別化を **題材（身近な生き物）と出典** に全振りすることになる。
逆に言えば、そこを緩めると何も残らない。[06-fact-checking.md](06-fact-checking.md) の基準は必ず守ること。

## 9. 成長の見かた（判断ライン）

投稿数と期間で切って、次に何を直すかを決める。

| 時点 | 見る指標 | 合格ライン | 下回ったとき直すもの |
|---|---|---|---|
| 〜30本 | 平均視聴維持率 | 70%以上 | 尺が長い。25秒に詰める |
| 〜30本 | 最初の3秒の離脱 | 25%以下 | フックが弱い。1行目を書き直す |
| 30〜60本 | 1本あたり再生 | 5,000以上 | ネタ選び。身近さが足りない |
| 60〜100本 | 登録者/再生 | 0.3%以上 | 締めの一言。次を見る理由がない |

**60本まではネタと型の検証期間。数字が動かなくてもフォーマットを変えない。**
変えるのは1要素ずつ（フック／尺／サムネ）。同時に変えると原因がわからなくなる。
