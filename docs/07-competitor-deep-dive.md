# 競合 深掘り分析（2026-09-16）

[02-market-research.md](02-market-research.md) の続き。生き物ショート専業の競合を、
タイトル・尺・投稿頻度・登録転換まで分解した。

## 1. 市場は4層に分かれている

| 層 | 例 | 規模 | 30日成長 | 評価 |
|---|---|---:|---:|---|
| **L1 転載量産** | ほっこりショート／なんか気持ちいい | 30〜55万 | 横ばい | 真似できない。すべきでもない |
| **L2 大手ゆっくり解説** | ゆっくり生物チャンネル 18.3万<br>古代生物ちゃんねる 10.4万 | 10〜18万 | **+0.55〜0.97%** | **成長が止まっている** |
| **L3 生き物ショート専業** | なるほどずかん 2.29万<br>ゆっくり生き物語 5.56万<br>ピヨ先生 1.03万 | 1〜6万 | +3〜13% | ここが実戦の相手 |
| **L4 急成長の新興** | 奇妙動物学 1,720<br>なぜ動物はこうなった? 3,480<br>生存ログ 3,430<br>もふ語り 6,040 | 1.7〜7千 | **+24〜183%** | いま参入できている証拠 |

**結論：市場は新規参入に開いている。**
L2の大手は月+1%未満で完全に止まり、L4の1,700〜7,000人規模が月+24〜183%で伸びている。
「もう飽和している」という状況ではない。

## 2. なるほどずかん の分解 — 最も学ぶべき相手

登録22,900／総再生9,349万／**平均383,160再生**。
登録者数の **16.7倍** が平均再生という異常値。

### 上位タイトル

| 再生 | タイトル | 尺 | 文字数 |
|---:|---|---:|---:|
| 2,084万 | 馬の蹄を削る理由 | 45秒 | 8字 |
| 912万 | カマキリに水をかける理由 | 31秒 | 12字 |
| 875万 | 時速110キロで飛んでくるカジキ | 44秒 | 15字 |
| 837万 | ヒョウだけ飼い方が違う理由 | 43秒 | 13字 |
| 586万 | 変な羽が生えてると思ったら | 43秒 | 13字 |
| 454万 | 砂浴びをする動物 | 27秒 | 8字 |
| 286万 | 柵がなくても動物が通れない道 | 29秒 | 14字 |

### わかったこと

1. **タイトルは全て体言止め、8〜15字。** 疑問符も煽り記号も一切使っていない。
2. **最強は「◯◯する理由」型**、しかも **人間が生き物にする行為の理由**。
   蹄を削る／水をかける／氷を与える／おむつをさせる。
   「見たことはあるが、なぜかは知らない」——好奇心の密度が最も高い場所。
3. **尺は27〜50秒**、上位は43〜45秒に集中。
4. **弱点：再生は出るのに登録されない。**
   平均38万再生で登録2.29万は、転換が極端に悪い。
   題材が馬・カジキ・ヒョウ・扁桃結石まで散らばっていて、
   **「このチャンネルを登録する理由」が視聴者に生まれない。**

> **ここが我々の勝ち筋。**
> タイトル型（体言止め「〜理由」）はそのまま採用し、
> 題材を**身近な生き物に限定**することで一貫性を作る。
> 同じ再生効率を保ったまま、登録転換だけを取りにいく。

## 3. 奇妙動物学（月+183%）の実体 — 真似してはいけない例

登録1,720／総再生444万／30日で登録+182.89%・再生+238.85%。
数字だけ見れば市場最速。中身を見ると別の話になる。

- **1日3〜5本**投稿。尺は全て61〜68秒で固定
- 日本語が不自然（「ヤマアラシの針は本当に飛ばすのかと聞かれる」「水牛はペットに最も適した動物だ」）
  → 他言語コンテンツの機械翻訳と推定される
- **同一タイトルの動画を1時間差で2本投稿**している（ヤマアラシ回、69,252再生と78,551再生）
- 登録1,720に対し総再生444万 → **量で再生は出るが、ブランドは何も残っていない**

**学べるのは投稿頻度だけ。** 品質戦略はこの逆を行く。

## 4. タイトル型の検証（vidIQ タイトルスコア）

同じ内容を書き方だけ変えて採点した結果。

| タイトル | 型 | スコア |
|---|---|---:|
| カラスの死体を見ない理由 | 体言止め「〜理由」 | **86** |
| なぜカラスの死体を見かけないのか | 疑問形 | 83 |
| セミの寿命が1週間ではない理由 | 体言止め「〜理由」 | **79** |
| セミが1週間で死ぬという誤解 | 体言止め（名詞） | 63 |
| セミは1週間では死にません | です・ます調の否定文 | 56 |

**結論**

1. **体言止め「〜理由」が最強。** 疑問形よりわずかに上、です・ます調より圧倒的に上。
2. **です・ます調の否定文は使わない**（56点）。同じ内容でも23点落ちる。
3. 常識の否定を扱うときも、「◯◯ではない**理由**」の形に落とす。

→ [03-shorts-format.md](03-shorts-format.md) と [05-publishing-checklist.md](05-publishing-checklist.md) の
タイトル規則をこの結果で更新済み。`s001`〜`s010` の第1候補も差し替え済み。

## 6. 使えなかった手法（記録）

**コメント分析（vidiq_comment_insights, niche=animal facts, language=ja）は不発。**

- コホート255チャンネルのうち、コメントを取得できたのは **9チャンネル・144件のみ**
- 抽出できた要望は1件（「コオロギよりダチョウ牧場を」）で、判断材料にならない

日本語ニッチでは現状この手法は機能しない。
**視聴者の要望は、自分の動画のコメントから拾うしかない。**
だからこそ、投稿初期にコメントを全部読んで返すことに意味がある
（→ [05-publishing-checklist.md](05-publishing-checklist.md) の「投稿後」）。
