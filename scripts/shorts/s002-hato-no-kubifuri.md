# 説明欄

```
【今回の問い】ハトはなぜ歩くとき首を振るのか

実は振っていません。頭を空間に固定したまま体を進め、
遅れた頭を一気に追いつかせている——それがあの動きの正体です。
景色が流れない状況では首振りが起きないことが実験で示されています。
```
