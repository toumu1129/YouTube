# 出典（確認済 2026-09-27）

- [x] （A）Hunt, N. H., Jinn, J., Jacobs, L. F., Full, R. J. (2021)
  「Acrobatic squirrels learn to leap and land on tree branches without
  falling」*Science* 373(6555): 697–700. DOI: 10.1126/science.abe5753
  → UCバークレー・キャンパス内に生息する野生のトウブキツネリス12頭を対象に、
    硬さの異なる（高・中・低の剛性）人工の枝から、隙間を越えてピーナッツの
    餌台へジャンプさせる実験を実施。計96回のジャンプを高速カメラで撮影・
    解析した。
  → リスは、跳ぶ位置を決める際に「跳躍距離」と「枝のしなり（たわみ）」の
    トレードオフを考慮しており、安定した跳び出し姿勢を、跳ぶ距離の短さ
    よりも約6倍重視していることが定量的に示された。硬い枝では餌台に
    近い（跳躍距離が短くなる）位置まで進んでから跳び、しなる枝では
    手前の早い位置から跳んでいた。台本の「柔らかい枝では早めに跳び、
    硬い枝では奥まで進んでから跳ぶ」「距離より跳ぶ瞬間の安定を優先」は
    この知見に基づく。
  → 初めて経験するしなる枝でも、リスは数回跳んだだけで踏み切りの力の
    加え方（インパルス）を調整し、跳び方を学習した。台本の「数回跳んだ
    だけで、跳び方を調整していた」はこの知見に基づく。
  → 着地に失敗しそうな場合、体をひねる・枝の下側に回り込む・鋭い爪で
    枝をつかむといった「パルクール」的な体勢立て直し行動によって、
    落下を回避する様子も確認された。台本の「体をひねったり爪で枝を
    つかんだりして、落ちずに体勢を立て直していた」はこの知見に基づく。
