# 出典（確認済 2026-10-01）

- [x] （A）Bastos, D. A., Zuanon, J., Rapp Py-Daniel, L., de Santana, C. D. (2021)
  「Social predation in electric eels」*Ecology and Evolution* 11(3): 1032–1038
  DOI: 10.1002/ece3.7121
  → ブラジル・アマゾンのイリリ川沿いにある、川とつながった小さな湖で、
    100匹を超える成体のヴォルタデンキウナギ（Electrophorus voltai、
    2019年に新種記載された種）が集まっているのを研究チームが発見。
    この湖で合計72時間の連続観察を行った。台本の「アマゾンの小さな湖で
    100匹以上のデンキウナギを72時間観察した」はこの手法に基づく。
  → 観察の結果、電気ウナギは単独で狩りをする夜行性の捕食者だと
    長く考えられてきたが、2〜10匹程度の小さなグループに分かれて小魚の
    群れを浅瀬に追い込み、取り囲んで同時に高電圧の電気ショックを
    浴びせる「協調的な集団狩り」を行っていることが確認された。台本の
    「2〜10匹の小さなグループに分かれて小魚の群れを取り囲み、同時に
    電気ショックを浴びせる狩りをしていた」はこの知見に基づく。
  → この狩りは主に夜明けや夕方に行われ、1回の狩りの儀式はおよそ1時間
    続き、その間に5〜7回の協調的な高電圧攻撃が繰り返された。台本の
    「夜明けや夕方に行われ、1時間の間に5〜7回も繰り返されていた」は
    この知見に基づく。
  → ヴォルタデンキウナギは、狩りの際に最大860ボルトの放電を行うことが
    知られており、これは確認されている動物の中で最も高い生体電圧と
    される。固定コメント案はこの知見に基づく。
