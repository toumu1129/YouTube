# 出典（確認済 2026-09-23）

- [x] （A）Frank, E. T., Buffat, D., Liberti, J., Aibekova, L., Economo, E. P.,
  Keller, L. (2024)「Wound-dependent leg amputations to combat infections
  in an ant society」*Current Biology* 34(14): 3273–3278
  DOI: 10.1016/j.cub.2024.06.021
  → フロリダアカアシオオアリ（Camponotus floridanus）を対象に、負傷した
    仲間の脚をどう手当てするかを実測。**大腿部（太もも側）の怪我は
    仲間が脚を噛み切って切断し、生存率は約90〜95%**。**脛節（すね側）に
    近い怪我は切断せず、傷口を舐めて消毒するだけで生存率は約75%**。
    未治療の場合の生存率はそれぞれ約40%、約15%まで下がる。
    台本の生存率の数値、切断／舐めるケアの使い分けはこの実測データに基づく。
  → 大腿部は筋肉量がすねの約10倍あり、体液（昆虫の血にあたるヘモリンパ）の
    循環を物理的に妨げるため、感染が全身に広がるまで時間的余裕がある
    （＝切断が間に合う）。一方すねは筋肉が少なく体液循環が速いため、
    感染が全身に回るスピードに切断が追いつかず、代わりに舐めて細菌を
    減らすケアが選ばれると考えられている。台本の「太ももの筋肉が血の
    流れを妨げる」「すねは切断が間に合わない」はこの知見に基づく。
