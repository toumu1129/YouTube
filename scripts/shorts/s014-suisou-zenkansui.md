# 説明欄

```
【今回の問い】水槽の水を全部替えてはいけないのはなぜか

ろ過材や砂利には、魚の出すアンモニアを害の少ない物質に変える細菌が住みついています。
水を全部替えるとこの細菌ごと失われ、処理されなくなったアンモニアで魚が中毒を起こします。
```

# 固定コメント案

ろ過材を水道水で洗うのも同じ理由で危険です。塩素で細菌が死にます。
洗うなら、飼育水か、カルキを抜いた水で。
