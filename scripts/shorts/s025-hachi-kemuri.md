# 説明欄

```
【今回の問い】養蜂家が蜂の巣箱を煙でいぶすのはなぜか

蜂は危険を感じると警報の匂いで仲間を呼びますが、煙はその伝達を妨げます。
さらに煙を感じた蜂は巣を離れる準備として蜜を吸い込み、
腹がふくれて体を曲げにくくなるため、刺しにくくなります。
```

# 固定コメント案

煙は「落ち着かせる」というより「連絡を取れなくする」に近いです。蜂が安心しているわけではありません。
