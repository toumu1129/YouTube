# 出典（確認済 2026-09-21）

- [x] （A）Hutchinson, J. R., Famini, D., Lair, R., Kram, R. (2003)
  「Are fast-moving elephants really running?」
  *Nature* 422: 493–494. DOI: 10.1038/422493a
  → タイの42頭の成体ゾウを高速度カメラで撮影・解析。**ゾウはどれだけ速く
    移動しても、4本の脚が同時に地面から離れる瞬間が一度もない**ことを
    実証した（研究チームはこの歩き方を、コミカルな前傾姿勢にちなみ
    「Groucho running」と呼んだ）。台本の「4本の脚が同時に地面から
    離れることはありません」はこの知見。
- [x] （B・専門家解説）同論文の筆頭著者John Hutchinson氏（英・王立獣医大学、
  生体力学専門）による解説：ゾウは足首の関節が硬く、下腿の筋肉も比較的
  弱く、太く短い腱を持つ「柱のような」脚の構造をしているため、跳躍に
  必要な「バネ」の役割を果たせない。
  参考：Live Science「Why Can't Elephants Jump?」
  https://www.livescience.com/54606-why-elephants-cannot-jump.html
  台本の「柱のような構造」「アキレス腱やふくらはぎの筋肉が発達して
  いません」はこの解説に基づく。

# 説明欄

```
【今回の問い】ゾウはなぜジャンプできないのか

ゾウはどんなに速く走っても、4本の脚が同時に地面から離れることは
ありません。脚の骨がほぼ一直線に重なる柱のような構造をしていて、
足首の関節も硬く、跳ぶために必要な太くて強いアキレス腱やふくらは
ぎの筋肉が発達していないためです。
もし無理に跳んで着地すれば、体重による衝撃で骨や関節に大きな負担
がかかってしまいます。
```
