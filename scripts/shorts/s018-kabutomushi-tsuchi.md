# 説明欄

```
【今回の問い】カブトムシの土を定期的に替えるのはなぜか

幼虫にとって土は寝床ではなく食べ物です。
腐った葉が分解された土を食べて育つため、飼育中は土が減り続け、
食べた分だけ糞が溜まります。表面の黒い粒がその糞です。
```

# 固定コメント案

交換のときに幼虫の糞を全部捨てる必要はありません。少し混ぜておくと環境が急に変わらずに済みます。
