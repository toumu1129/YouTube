# ネタ帳

**95本ぶん。** 上から順に使っていけば約3か月半もつ。

**まず「人間の行為の理由」セクション（#81〜#95）から消化すること。**
競合分析でこの型が最も強いとわかったため（→ [07-competitor-deep-dive.md](../../docs/07-competitor-deep-dive.md)）。

- **型** … A感情ラベル / B なぜ疑問 / C 常識の否定 / D 不在の謎 / E 意外な対戦
- **裏取り** … ◎すぐ出典が出る ／ ◯少し調べれば出る ／ △要注意（通説が混ざっている）
- 使ったら「済」列に台本IDを書く

## 人間の行為の理由（最強型・[07](../../docs/07-competitor-deep-dive.md) で発見）

なるほどずかん（平均38万再生）の上位を分解して出てきた型。
「馬の蹄を削る理由」2,084万、「カマキリに水をかける理由」912万、「ヒョウだけ飼い方が違う理由」837万——

## ネタの足しかた

1本作るごとに、**視聴者のコメントから1本拾う。** 「じゃあ◯◯は？」が最良のネタ元になる。
自分で思いつくネタは必ず尽きるが、コメントは尽きない。

追加するときは、次の3つを満たすか確認する。

- [ ] その生き物を、視聴者は**今週どこかで見かける**か
- [ ] 問いを**1行**で書けるか
- [ ] 答えを**1つ**に絞れるか

3つとも満たせないネタは、長尺向き。ショートには入れない。
