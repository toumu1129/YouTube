# s020 素材

画像のみの動画（音声・テロップなし）を組んだときの素材一式。

| ファイル | 用途 | 秒 | 出どころ |
|---|---|---:|---|
| `f1.jpg` | 牛 | 2.88 | Pexels / Gizem Gökce（**クレジット必須**） |
| `f2.jpg` | 牛用磁石 | 3.84 | 自作図解 |
| `f3.jpg` | 草ごと金属を飲み込む | 12.48 | 自作図解 |
| `f4.jpg` | 第二胃に磁石が留まる | 6.72 | 自作図解 |
| `f5.jpg` | 牛 | 2.88 | Pexels / Los Muertos Crew（**クレジット必須**） |

図解は `draw3.py`（Pillow）で生成。数値を変えれば描き直せる。

## 組み立て

```
ffmpeg -f concat -safe 0 -i list.txt \
  -vf "fps=30,format=yuv420p" -c:v libx264 -preset medium -crf 20 -an out.mp4
```

出力：1080×1920 / 30fps / 28.83秒 / 音声なし

## 積み残し

- **③が12.48秒。1枚で持たせるには長すぎる。** 実制作では2〜3カットに割る
- 図解は仮。牛のシルエットと胃の形は作り直す余地がある
